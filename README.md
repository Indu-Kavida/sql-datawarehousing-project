# SQL Data Warehousing Project

## Overview
This project focuses on building a modern SQL-based Data Warehouse to consolidate and analyze sales data from multiple business systems. The solution is designed to support analytical reporting, business intelligence, and data-driven decision making.

The project demonstrates Data Engineering and Data Analytics concepts including:
- Data Integration
- Data Cleaning & Transformation
- SQL-based Analytics
- Reporting & Insights
- Dimensional Data Modeling

---

# Project Requirements

## Building the Data Warehouse (Data Engineering)

### Objective
Develop a modern data warehouse using SQL Server to consolidate sales data, enabling analytical reporting and informed decision-making.

### Specifications
- Import data from ERP and CRM systems provided as CSV files.
- Cleanse and resolve data quality issues before analysis.
- Integrate multiple data sources into a single analytical model.
- Focus on the latest dataset only.
- Provide proper documentation for business and analytics teams.

---

# BI: Analytics & Reporting (Data Analytics)

Develop SQL-based analytics to generate insights related to:

- Customer Behavior
- Product Performance
